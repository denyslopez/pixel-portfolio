## Canonical creative direction

R3 thesis: **CONTROLLED ENERGY**

Cinematic restraint × technical signal × editorial precision × contemporary product engineering.

Core visual language:
- Carbon / graphite foundation
- Warm off-white typography
- Signal Vermilion as the single warm activation color
- Contemporary grotesk as the primary voice
- Editorial serif only as selective contrast
- Technical mono for metadata and system labels
- Integrated cinematic imagery
- Peripheral atmospheric motion / flow fields
- No ornamental orbit or decorative 3D sculpture

## Key screen 01 — Desktop Home

Purpose: establish Denysoft positioning, visual identity and immediate commercial clarity.

Requirements:
- 12-column composition
- controlled left-aligned hero statement: `I BUILD INTELLIGENT DIGITAL PRODUCTS.`
- `INTELLIGENT` receives Signal Vermilion emphasis but stays on the same compositional axis
- cinematic visual aperture integrated into hero
- CTA pair visible immediately
- geographic narrative visible without competing with headline
- no floating headline line
- no decorative orbit
- technical microcopy remains secondary

## Key screen 02 — Desktop Selected Work

Purpose: prove breadth without card soup.

Requirements:
- three flagship projects only: Baltica Salon / Taller Express / MasterTax
- cinematic project imagery integrated into charcoal system
- image treatment may use low saturation, controlled contrast, vermilion activation and tonal masking
- each project identifies category and role clearly
- layout may be modular/asymmetric but reading order must remain obvious
- no fabricated metrics
- real project evidence must replace concept imagery before production

## Key screen 03 — Mobile Home

Purpose: preserve the same identity as desktop without scaling the desktop composition down.

Requirements:
- dedicated mobile composition
- headline fully readable with conservative line breaks
- primary CTA visible in first interaction range
- living visual aperture behind/below content without reducing contrast
- navigation available and non-obstructive
- EN/ES line lengths handled independently
- peripheral motion reduced relative to desktop
